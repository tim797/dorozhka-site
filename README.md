# ДОРОЖКА — результаты плавания

## 1. Установка

Нужен Node.js 18+.

```bash
npm install
```

## 2. Supabase

1. Создайте проект в Supabase.
2. Откройте SQL Editor.
3. Вставьте содержимое `supabase.sql`.
4. В настройках проекта найдите Project URL и anon/public key.
5. Скопируйте `.env.example` в `.env`.
6. Заполните:

VITE_SUPABASE_URL=...
VITE_SUPABASE_ANON_KEY=...

## 3. Запуск

```bash
npm run dev
```

Откройте адрес, который покажет Vite.

## 4. Публикация

Проект можно разместить на Vercel, Netlify или другом хостинге для Vite.

Важно: в текущем SQL загрузка и удаление открыты публично для первого теста. Перед реальным запуском нужно сделать вход администратора для тренера и закрыть INSERT/DELETE для обычных посетителей.

## Что умеет

- загрузка XLS/XLSX протоколов;
- общая онлайн-база;
- поиск пловца;
- история результатов;
- личный рекорд;
- график прогресса;
- просмотр соревнований;
- удаление протокола;
- обработка времени Excel.
